# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

NetSpeedLite is 100% local software with zero network telemetry, zero background servers, and zero remote connections. All network statistics are read strictly from local Windows kernel interfaces via standard OS APIs.

If you discover a security issue or unexpected behavior:
1. Please open an issue via [GitHub Issues](https://github.com/git-ysf/NetSpeedLite/issues).
2. Detail the exact steps and conditions to reproduce the issue.
3. Fixes will be reviewed and published promptly.
